# Frontend: структура и визуальная система

Обновление 2026-10-08. React-компоненты строятся через композицию.
Redux slices хранят состояние и операции с API; страницы связывают данные
с интерфейсом. Классы не добавляются без поведения, которому они нужны.

## Переиспользование

- `components/ui/Icon.tsx`: единый набор SVG-иконок.
- `components/ui/FormField.tsx`: видимая подпись, стабильный id и input props.
- `features/auth/AuthForm.module.css`: общий стиль обеих auth-форм.
- `components/StoragePreview`: декоративный пример хранилища на главной.
- `config/project.ts`: ссылки автора, без дублирования адресов в footer.
- `index.css`: цветовые переменные, типографика, focus и reduced-motion.

Общие компоненты не выполняют API-запросы. Декоративный preview не притворяется
реальными пользовательскими данными. CSS Modules ограничивают область стилей.
Главная, формы, хранилище, админ-панель и диалоги используют одну палитру.

## Поведение

Поиск фильтрует уже загруженные файлы через useDeferredValue.
Dropzone работает с клавиатуры. Формы имеют подписи и autocomplete.
Диалог удерживает фокус, закрывается по Escape и возвращает фокус.
Footer содержит имя Дмитрия Морозова, Telegram и репозиторий My Cloud.

## Проверки

Перед публикацией: TypeScript/build, ESLint, просмотр desktop и mobile 390px.
После публикации: auth flow, сохранение сессии, файлы и отсутствие старых
учебных ссылок. Backend и его данные при редизайне не изменяются.
