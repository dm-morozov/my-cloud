# Статус проекта

## Этап

Перенос My Cloud на Selectel и подготовка frontend к GitHub Pages (2026-10-08).
Backend и SPA реализованы. Актуальная инструкция: [[deployment/docker-pages]].

## Уже сделано

- Репозиторий переименован в `dm-morozov/my-cloud`.
- Подготовлены Dockerfile, Compose и GitHub Pages workflow.
- Backend запущен закрыто на Selectel; 34 теста проходят, миграции применены.
- Добавлены лимиты загрузки, квота, безопасная выдача файлов и CSRF-защита входа.

- Создан корневой каркас `docs`.
- Вынесены материалы Netology.
- Подготовлены разделы для архитектуры, API, задач и решений.
- Добавлена рабочая зона для временных файлов и заметок.
